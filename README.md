# 📊 Sales Data Analysis Using Python

## 📌 About the Project
This project focuses on analyzing sales data using Python and Pandas. The main objective is to explore sales performance, clean the dataset, extract meaningful insights, and understand customer purchasing behavior.

It is a practical beginner-level project designed to build fundamental data analysis skills.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 🔍 Project Workflow

### 1. Data Exploration
- Loaded and inspected the dataset.
- Reviewed dataset structure and statistical summaries.
- Checked columns and data types.

### 2. Data Preparation
- Identified missing values and duplicate records.
- Checked and corrected data types where needed.
- Verified revenue calculations using quantity and unit price.

### 3. Exploratory Data Analysis (EDA)
- Calculated overall revenue.
- Analyzed sales performance by product and category.
- Examined monthly revenue trends.
- Studied order sizes and customer purchasing patterns.

### 4. Data Visualization
- Created a line chart to track monthly sales.
- Used bar charts to compare order size distribution.

## 📈 Key Findings
- **Best-Selling Product:** Laptops.
- **Leading Category:** Electronics.
- **Peak Sales Months:** November, October, and July.
- **Average Order Value:** Approximately $1,106.
- **Average Items per Order:** Around 2.5 items.
